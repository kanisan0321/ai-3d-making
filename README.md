# 3Dが作れなかった自分が、AIと組んで頭の中のものを形にした話

## ひとことで

**Claude Code（AI）にBlenderやUnityの作業を任せる方法を自分で調べて試し、3Dモデルを1つも作れなかった状態から、約3週間でゲームとVRChatワールドの2本を形にしました。**

## きっかけ

ゲームプランナーとして、作りたいもののイメージは頭の中にありました。でも、3Dオブジェクトを作る技術がなかったので、自分ではそれを形にできませんでした。

2026年10月末に、AIとBlender・Unityをつなぐ方法を調べ始めました。Blender用やUnity用のMCP（AIがツールを操作するための仕組み）、Claude Codeにスクリプトを書いてもらう方法などを比べて、実際に試しました。

## どこまで試したか

### ① ゲーム「マホメイド」（チーム制作・Unity）

サーバー・クライアント型のオンラインゲームです。私はリーダー兼リードプランナーです。チームに3Dモデラーがいなかったので、3Dモデルも自分で担当することにしました。

- **期間**：2026/11/4〜11/19（約2週間）
- **作り方**：Claude Codeに書いてもらったPythonスクリプトで、Blenderでモデルを作る
- **作ったもの**：3Dモデル71個、すべて自作（円形の闘技場のマップ、廃墟の装飾、植物系ボス「根裂く花」の試作モデルなど）
- **モデル以外**：ボス登場のカットシーン、ボスの攻撃の種類、協力のしくみの検証（描いて起こす・属性の共鳴・合わせ描き）
- **試して戻したこと**：UnityとAIを直接つなぐ Unity MCP を入れてみましたが、チームのプロジェクトに合わなかったので取り消しました

### ② VRChatワールド「グラフィティ」（個人制作）

壁にスプレーで落書きできるVRChatのワールドです。

- **作り方**：Claude Codeに書いてもらったPythonスクリプトで、Blenderの街（路地・高架下・屋上など）を組み立てる。小物の一部は無料の3D素材（Poly Haven）を使い、ワールドに合わせて軽くした
- **期間**：Gitで管理を始めた 2026/11/16 から 11/18 までの3日間で、コミット27回
- **作ったもの**
  - スプレー機能を5段階で実装（かすれ・垂れ、缶を振る音と振動、型（ステンシル）80個、スポイトなど）
  - 仕様書14冊と試験の記録を作り、AIの作ったものを仕様と突き合わせて直した
- **軽量化**：小物の三角形を85万→60万、テクスチャを451MB→379MBに削減

## 効果

- **できなかったことが、できるようになった**：3Dモデルを1つも作れなかった状態から、約3週間でゲームとワールドの2本を形にできました。チームに3Dモデラーがいなくても、ゲームを止めずに進められました。
- **頭の中のイメージを、すぐ見られる形にできる**：言葉で伝えたものがその場で形になるので、「本当に面白いか」をすぐ確かめられます。
- **AIに任せるためのルールづくりも学んだ**：AIは指示が曖昧だと間違えます。仕様書を先に書き、試験の記録を残して、AIの作ったものを仕様と突き合わせる流れを作りました。プランナーとして「伝わる仕様を書く」練習にもなっています。

## おまけ：就活の書類を、AIとの壁打ちで作る

- **きっかけ**：自己PRを自分で書くと、どこかで見たような就活用語ばかりになり、自分らしさが消えていました。
- **ChatGPTからClaudeへの引き継ぎ**：もともと就活の相談はChatGPTでしていました。Claudeに乗り換える時、ChatGPTの会話データを書き出し、これまでの相談内容を引き継ぎ資料にまとめて渡しました。資料には古い情報もあったので、選考の状況を1つずつ確認し直して、今の状態にそろえました。
- **やり方**：AIに完成文は書かせず、質問してもらって自分で答える形にしました。「言っていない経験を足さない」「自分の言葉を就活用語に置き換えない」をルールにし、制作物の数字は記憶ではなくGitの記録から拾いました。
- **効果**：乗り換えても、一から説明し直さずに相談を続けられました。また、自分では気づいていなかった強みの根拠（チームの意見が割れた時に、ターゲットから逆算して方向を決めた経験など）を、自分の言葉で書けるようになりました。
